# Flutter Learning Project

A hands-on Flutter project created to learn and practice Flutter and Dart concepts through practical implementation.

This repository contains examples and features that I am building while learning Flutter, with a focus on understanding how Flutter works internally and following clean, maintainable development practices.

## 🚀 About the Project

This project is part of my journey from React Native development to Flutter development.

The goal is not just to build an application, but to understand the core concepts behind Flutter, including:

* How Flutter widgets work
* Widget, Element, and Render trees
* StatelessWidget and StatefulWidget
* Widget lifecycle
* Layout and constraints
* Navigation
* Forms and user input
* State management
* Riverpod
* API integration
* Asynchronous programming
* Reusable widgets
* Flutter project structure
* Dart language fundamentals

## ⚙️ Getting Started

### Prerequisites

Make sure you have Flutter installed.

Check your Flutter installation:

```bash
flutter doctor
```

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
```

Navigate to the project:

```bash
cd YOUR_REPOSITORY_NAME
```

### Install Dependencies

```bash
flutter pub get
```

### Run the Application

```bash
flutter run
```

You can also run the project on:

* Android Emulator
* iOS Simulator
* Physical Android device
* Physical iOS device
* Chrome/Web
